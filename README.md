# Interactive 3D Drink Menu

A mobile-friendly simulated-3D menu created from six single-view drink photographs.

## Controls

- Tap a drink to play its cinematic reveal.
- Drag or swipe to rotate and tilt.
- Pinch or scroll to zoom.
- Use the large buttons for replay, auto rotation, zoom, and reset.
- Enable **Reduce motion** for a steadier experience.

> This is a simulated 3D presentation. True inspection of unseen angles requires multi-angle photography or GLB models.
